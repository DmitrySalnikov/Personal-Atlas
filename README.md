# personal_atlas

Интерактивная карта стран, в которых я побывал, и тех, куда собираюсь.

Одна самодостаточная HTML-страница: открывается локально, без сборки и зависимостей.

## Что внутри

- карта мира в проекции Робинсона с центральным меридианом 10° в.д., границы Natural Earth 1:10 млн;
- три статуса — «был», «хочу», «не был» — и заметка к каждой стране;
- таблица по 23 регионам UN M49 и шести континентам со счётчиками и прогрессом;
- наведение подсвечивает страну на карте и в списках, клик выделяет, регион или континент выделяются целиком;
- масштабирование колесом и перетаскивание карты;
- два языка (RU / EN) и две темы, выбор запоминается в браузере.

## Как править данные

Все данные — в начале файла, в блоке `<script>`:

```js
const VISITED = { "italy": "Рим и Флоренция, октябрь 2019", ... };  // ключ: заметка
const WISHLIST = { "japan": "Киото весной" };                       // куда хочется
const EXTRA = [ { key: "abkhazia", name: "Абхазия", ... } ];        // территорий нет в наборе границ
const WORLD_TOTAL = 195;                                            // знаменатель для доли
```

Ключ страны — латинский слаг (`sri-lanka`) либо название на русском или английском. Полный список ключей печатается в консоли браузера. Всё остальное — карта, счётчики, таблица, сводка — пересобирается само.
